## ポートフォリオ用タイトル

あと5分カウンター — 先延ばしで崩壊する予定を可視化するPWA

## 一言説明

「あと5分」の積み重ねを、時間・回数・赤さで容赦なく見せる先延ばしカウンター。

## 紹介文（200〜400文字）

「あと5分だけ」を何度も繰り返した結果、予定がどれほど崩壊したかを可視化するモバイルファーストのWebアプリです。ボタンを押すたびに開始予定時刻が5分ずつ後ろへずれ、累計延期時間、押した回数、崩壊メーター、段階的に諦めていくメッセージを表示。延期するほど画面が赤くなる演出で、先延ばしの罪悪感まで楽しく表現しました。履歴と本日の合計は端末内に保存され、1回戻す・リセット・XやWeb Share APIでの共有にも対応。ライト／ダークモード、キーボード操作、PWA、モーション軽減など、くだらない題材を真面目に使いやすく仕上げています。

## 主な機能

- 予定名と本来の開始時刻を設定
- 1タップで5分延期し、現在の開始予定時刻を自動更新
- 累計延期時間、押した回数、本日の先延ばし合計を表示
- 延期時間に連動するメッセージ、崩壊メーター、赤色演出
- 1回戻す、リセット、履歴の端末内保存
- X / Web Share API / クリップボードによる結果共有
- ライト・ダークモード、キーボード操作、PWA対応

## 使用技術

Next.js（App Router）、React、TypeScript、Tailwind CSS、localStorage、Web Share API、Clipboard API、PWA、Vercel Analytics、Playwright、Vercel
